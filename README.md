
# 🏥 Health Indicators Dashboard

An interactive Power BI dashboard designed to provide insights into key health metrics, enabling stakeholders to monitor and analyze critical health indicators effectively.

---

## 📊 Dashboard Overview

The Health Indicators Dashboard offers a visual representation of essential health metrics, facilitating data-driven decision-making. Key features include:

- **Dynamic Visualizations**: Interactive charts and graphs that update based on user selections.
- **Filter Capabilities**: Slicers and filters to drill down into specific data segments.
- **KPI Monitoring**: Real-time tracking of vital health indicators.

---

## 🛠️ Tools & Technologies

- **Power BI**: For creating interactive visualizations and dashboards.
- **Microsoft Excel**: Used as the primary data source.
- **Power Query**: For data transformation and cleaning processes.

---

## 📂 Project Structure

```
health-indicators-dashboard/
├── data/
│   └── health_data.xlsx
├── dashboard/
│   └── health_indicators_dashboard.pbix
├── README.md
```

- `data/health_data.xlsx`: Contains the raw health data used in the dashboard.
- `dashboard/health_indicators_dashboard.pbix`: The Power BI dashboard file.
- `README.md`: Project documentation.

## 🚀 Getting Started

To view and interact with the dashboard:

1. **Clone the Repository**:
   ```bash
   git clone https://github.com/parbatrajpurohit/health-indicators-dashboard.git
   ```

2. **Open the Dashboard**:
   - Navigate to the `dashboard` folder.
   - Open `health_indicators_dashboard.pbix` using Power BI Desktop.

3. **Explore the Dashboard**:
   - Use the interactive elements to filter and analyze the data based on various health indicators.

---

## 📈 Key Metrics Visualized

- **Patient Admission Rates**: Trends over time.
- **Treatment Outcomes**: Success rates across different departments.
- **Resource Utilization**: Bed occupancy and equipment usage.
- **Staff Performance**: Metrics related to healthcare providers.

---

## 🧹 Data Transformation Steps

Before visualization, the data undergoes several transformation steps using Power Query:

- **Data Cleaning**: Removing duplicates and handling missing values.
- **Data Formatting**: Ensuring consistent data types and formats.
- **Calculations**: Deriving new metrics such as average treatment duration.
